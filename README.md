## Objective

Analyze NorthByte Airlines' financial and operational data to identify the main drivers of declining profitability and develop data-supported recommendations.

## Project Structure

- `data/raw/`: Original datasets provided for the case
- `data/processed/`: Cleaned and processed datasets
- `notebooks/`:  Data cleaning and analysis notebooks

## Datasets

The case includes three datasets:

- `transactions.xlsx`: Customer transactions, ticket revenue, ancillary purchases, and refunds
- `costs.xlsx`: Flight operating costs including fuel, crew, maintenance, and food
- `gates.xlsx`: Airport gate leases and associated costs

## Analysis

Main areas of analysis:

1. Overall revenue, costs, and profitability
2. Route-level profitability
3. Airport and gate costs
4. Refunds and ancillary revenue
5. Customer and Rewards program analysis
6. FY2026-27 gate cost estimates
7. Recommendations to improve profitability
